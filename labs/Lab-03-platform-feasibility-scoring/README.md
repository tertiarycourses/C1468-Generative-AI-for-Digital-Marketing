# Lab 03: Platform feasibility scoring → TikTok short-video feasibility

C1468 • v1.0 • Synthetic teaching scenario

## Scenario
Harbour & Grove is a fictional Singapore home-goods SME launching a reusable desk organiser. The retail price is S$39; estimated contribution margin is S$14 per order. No real customer or platform data is included.

## Deliverables
- platform selection matrix; decision: Pilot only channels above threshold and with owner.
- format-to-CTA map; decision: Use motion where demonstration adds evidence.
- cross-placement plan; decision: Keep creative adapted to placement context.
- B2B pilot rationale; decision: Test only when deal economics support cost.
- video pilot decision; decision: Require native-format proof before budget scale.

## Detailed procedure
1. Set platform weights for audience fit, format fit, cost and team capacity; ensure weights sum to 100%.
2. Score Instagram, Facebook, LinkedIn and TikTok from 1–5 using written evidence and assumptions.
3. For Instagram, map Feed, Stories and Reels to the customer journey and asset requirement.
4. Specify one native-format creative adaptation for each shortlisted platform.
5. Estimate production effort and response capacity; compare with the available team hours.
6. Apply a threshold and select one pilot platform plus one reserve; save the scoring matrix.

## Acceptance checks
- No real personal information or unlicensed customer content.
- A named source for every factual claim.
- One explicit reviewer decision per output.
- The mock campaign remains unpublished.
