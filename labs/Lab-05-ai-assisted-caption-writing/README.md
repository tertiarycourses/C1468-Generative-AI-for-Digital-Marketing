# Lab 05: AI-assisted caption writing → Creative variant matrix

C1468 • v1.0 • Synthetic teaching scenario

## Scenario
Harbour & Grove is a fictional Singapore home-goods SME launching a reusable desk organiser. The retail price is S$39; estimated contribution margin is S$14 per order. No real customer or platform data is included.

## Deliverables
- caption shortlist; decision: Human reviewer checks every fact and tone.
- tag and location plan; decision: Keep only tags tied to intent and geography.
- image generation brief; decision: Review hands, product fidelity and disclosure need.
- shot-by-shot storyboard; decision: Cut scenes that do not advance message.
- six-cell test matrix; decision: Test one causal variable per comparison.

## Detailed procedure
1. Write three caption hooks from the approved product sheet; add benefit, evidence and CTA to each.
2. Select hashtags by topic relevance and geography, recording why each tag fits the audience.
3. Use the editable SVG marketing asset as a wireframe; define a separate AI image brief with product-fidelity constraints.
4. Storyboard a 15-second video: hook, demonstration, evidence and CTA with time per shot.
5. Build a six-cell test matrix from three hooks and two visuals; label the one variable compared in each test.
6. Reject any generated claim or visual that misrepresents the fictional product; save corrected assets.

## Acceptance checks
- No real personal information or unlicensed customer content.
- A named source for every factual claim.
- One explicit reviewer decision per output.
- The mock campaign remains unpublished.
