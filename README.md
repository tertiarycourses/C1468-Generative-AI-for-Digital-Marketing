## Course Outcomes

- **LO1** — Develop a plan and objectives for a social marketing campaign
- **LO2** — Evaluate opportunities and the feasibility of social media platforms
- **LO3** — Create a generative AI social media campaign and monitor its outcome
- **LO4** — Evaluate AI campaign use and organisational impact

## Lab Activities

The eight labs form one connected practical journey. Complete them in order so each verified output can support the activities that follow.

| # | Activity | Folder |
|---:|----------|--------|
| 01 | Campaign objective and KPI tree → Campaign brief and brand voice | [Lab 01](labs/Lab-01-campaign-objective-and-kpi-tree/) |
| 02 | Content pillar allocation → Campaign economics | [Lab 02](labs/Lab-02-content-pillar-allocation/) |
| 03 | Platform feasibility scoring → TikTok short-video feasibility | [Lab 03](labs/Lab-03-platform-feasibility-scoring/) |
| 04 | Audience overlap and exclusions → Pilot test design | [Lab 04](labs/Lab-04-audience-overlap-and-exclusions/) |
| 05 | AI-assisted caption writing → Creative variant matrix | [Lab 05](labs/Lab-05-ai-assisted-caption-writing/) |
| 06 | Ad campaign hierarchy → Community response triage | [Lab 06](labs/Lab-06-ad-campaign-hierarchy/) |
| 07 | Tracking event map → Frequency and fatigue | [Lab 07](labs/Lab-07-tracking-event-map/) |
| 08 | A/B test interpretation → Organisational impact review | [Lab 08](labs/Lab-08-a-b-test-interpretation/) |

All lab scenarios use synthetic data. No real customer or platform data is included.
